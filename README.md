# HI-LOW / SniperGold V10 — Complete Cordova Source Package

This package is based on the supplied `SNIPERGOLD-V10-FINAL-WIRING-IMPROVED.html`.
The HTML is installed as `www/index.html` without replacing its application logic.

## Included
- `www/index.html` — supplied SniperGold V10 HTML
- `config.xml` — Cordova application configuration
- `package.json` — Cordova/Android build dependencies
- `res/icon/` — universal Android launcher PNG/XML resources
- `res/drawable/` — launcher foreground/background assets
- `.github/workflows/android.yml` — GitHub Actions debug APK build
- `src/`, `ui/`, `data/` — reserved project folders; the current app is intentionally HTML-first

## Important
`platforms/android/`, Gradle wrapper files, `node_modules/`, and `plugins/` are generated by Cordova during the build. They should not be manually fabricated into the source package.

The supplied HTML loads Lightweight Charts and Tailwind from HTTPS CDNs and uses HTTPS market-data endpoints. Its local Optimistic font declarations remain fallback-safe if the font files are not present.

## Local Termux build
```bash
cd HI-LOW-SNIPERGOLD-V10-COMPLETE
npm install
npx cordova platform add android
npx cordova build android --debug
```

APK output:
`platforms/android/app/build/outputs/apk/debug/app-debug.apk`

## GitHub
Push this folder to the `main` branch. The included workflow will generate a debug APK as a GitHub Actions artifact.
